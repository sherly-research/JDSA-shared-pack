# Lexicons

This folder contains preprocessing and rule-based extraction resources used in the proposed HYBRID-ATE pipeline.

- `slangword.txt`: slang normalization list used in both UNSUP-ATE and RB-ATE preprocessing.
- `custom_stopwords.txt`: custom stopword list used in both UNSUP-ATE and RB-ATE preprocessing.
- `interjeksi_stopwords.txt`: interjection/noise word list used in RB-ATE filtering.
